# سامانه پرسش از اسناد (LLM RAG System)

این سامانه یک سیستم هوشمند مبتنی بر RAG است که با استفاده از Django، LangChain و Docker پیاده‌سازی شده است. این سیستم امکان آپلود فایل‌های `.docx`، پردازش و استخراج متن کامل هر سند، و پرسش‌وپاسخ هوشمند از روی اسناد را با استفاده از مدل‌های زبانی ارائه می‌دهد.

## الزامات و ابزارها

- Docker و Docker Compose
- Django (برای بک‌اند و رابط کاربری ادمین)
- LangChain (برای زنجیره پردازش و RAG)
- ChromaDB (به عنوان پایگاه داده برداری لوکال)

## مراحل راه اندازی پروژه

۱. ابتدا یک فایل `.env` در ریشه پروژه (کنار فایل `docker-compose.yml`) ایجاد کرده و مقادیر زیر را در آن قرار دهید:

```env
# کلید API سایت OpenRouter برای اتصال به مدل زبانی
OPENROUTER_API_KEY=your_api_key_here

# جلوگیری از خطای پردازش موازی در Tokenizerها
TOKENIZERS_PARALLELISM=false

```

۲. پروژه را با استفاده از داکر بیلد و در پس‌زمینه اجرا کنید:

```bash
sudo docker compose up -d --build

```

۳. پس از اجرای موفق کانتینرها، دیتابیس را مایگریت کرده و کاربر ارشد (Admin) بسازید:

```bash
sudo docker compose run --rm web python manage.py migrate
sudo docker compose run --rm web python manage.py createsuperuser

```

۴. اکنون پنل مدیریت برای مدیریت اسناد در آدرس زیر در دسترس است:

- `http://localhost:8000/admin`

## مستندات API

سامانه یک API کامل برای ثبت پرسش و دریافت پاسخ تولید شده بر اساس اسناد ارائه می‌دهد. تاریخچه پرسش‌ها و پاسخ‌ها نیز به صورت خودکار در دیتابیس ذخیره می‌شود.

### ثبت پرسش و دریافت پاسخ

- **آدرس (Endpoint):** `/api/ask/`
- **متد:** `POST`
- **ساختار بدنه درخواست (JSON):**

```json
{
  "question": "سوال شما درباره متن اسناد آپلود شده؟"
}
```

- **ساختار پاسخ موفق (200 OK):**

```json
{
  "question": "سوال شما درباره متن اسناد آپلود شده؟",
  "answer": "پاسخ دقیق تولید شده توسط مدل زبانی بر اساس اسناد بازیابی شده."
}
```

- **ساختار خطای اعتبارسنجی (400 Bad Request):**

```json
{
  "error": "لطفا یک سوال (question) ارسال کنید."
}
```

## نکات فنی پیاده‌سازی

- به منظور جلوگیری از تداخل در پردازش‌های همزمان (Thread Deadlock) در ChromaDB و مدل‌های پردازش زبان، سرور جنگو با پرچم `--nothreading` اجرا شده است.
